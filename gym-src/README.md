# Safsf Gym Plan ❤️ — source

Safsf's gym app: weekly training plan, guided workouts, every set / rep / weight logged,
body-weight curve, stats, PRs and a muscle map. Pink theme, runs fully in the browser —
data stays on her phone (Settings → Export backup to save a copy).

Live: https://noureldin0007.github.io/safa-interpreter-bootcamp/gym/

Rebuild after changing anything in `src/`: `./build.sh` (runs tests, builds, refreshes `../gym/`).

Based on [openGym](https://github.com/DuarteSantos8/openGym) (AGPL-3.0, see `LICENSE` and `NOTICE.md`).
Exercise images/animations: hasaneyldrm/exercises-dataset, loaded from jsDelivr.
